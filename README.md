# Vue Anime  

Приложение для поиска, просмотра и загрузки аниме в формате **Electron**. Разработано с использованием **Vue.js 3**.  
Проект позволяет искать аниме, получать видеоплеер и отображать доступные торрент-файлы с rutracker.org (магнитные ссылки).  

---

## 📋 Основные возможности  
- **Поиск аниме по ссылке**:  
  - Получение ID из базы видеоконтента.  
  - Вывод встроенного плеера для воспроизведения аниме.  
- **Скачивание аниме**:  
  - Отображение доступных торрентов с rutracker.org (магнитные ссылки).  
- **Интерфейс на Vue.js 3**:  
  - Удобный и минималистичный дизайн.  

---

## 🚀 Установка и запуск  
### Требования  
- **Node.js** (версии 14.x или выше)  
- **npm**  

### Инструкции  
1. Склонируйте репозиторий:  
   ```bash
   git clone https://github.com/TheFlowDEV/vue_anime_public.git
   cd vue_anime_public
   ```
Установите зависимости:

```bash
npm install
```
Запустите приложение в режиме разработки:

```bash
npm run electron:serve
```
Для сборки проекта:
```bash
npm run electron:build
```
### 🛠️ Используемые технологии
- Electron: создание десктопного приложения.
- Vue.js 3: современный фреймворк для создания интерфейсов.
- JavaScript: основной язык разработки.
- Парсинг данных: для получения информации о видео и торрентах.
### 📂 Структура проекта
- src/: исходный код приложения.
- public/: статические файлы и ресурсы.
- package.json: зависимости и скрипты для работы проекта.
### ❓ Часто задаваемые вопросы
1. Какие платформы поддерживаются?
Приложение поддерживает Windows, macOS и Linux.

2. Есть ли ограничения на скачивание?
Для загрузки магнитных ссылок требуется наличие установленного торрент-клиента.
